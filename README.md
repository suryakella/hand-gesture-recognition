# Hand Gesture Recognition System

## Overview
This project detects hand gestures in real-time using a webcam. It uses MediaPipe for hand tracking and OpenCV for video processing.

## Features
- Real-time hand detection
- Finger tracking using landmarks
- Gesture recognition logic
- Action triggering based on gestures

## Tech Stack
- Python
- OpenCV
- MediaPipe

## How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Run the program:
python main.py
